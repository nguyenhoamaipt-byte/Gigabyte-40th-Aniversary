## Design system

- **Concept:** "Enter Infinity" — 40 years as forward momentum (Past → Present → Next 40)
- **Theme:** dark premium + vibrant orange (`#FF6A1A`); pop accents pink/cyan; 4 track colours (E orange · M violet · O blue · P green)
- **Type:** Space Grotesk (headings) + DM Sans (body)
- **Timeline:** 6 months (T6–T11) · 3 phases **IGNITE → RISE → INFINITY** · Big Event at T11 (peak)
